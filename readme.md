# Tic Tac Toe 🎮

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.

## 🚀 Features
- Two-player gameplay
- Interactive game board
- Winner detection
- Simple and clean user interface

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Project Structure
- `index.html` — Game structure
- `style.css` — Game styling
- `app.js` — Game logic
